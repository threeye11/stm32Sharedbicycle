# stm32-
基于 STM32 的智能共享单车控制系统 课设
一、项目整体概述
本项目以STM32 单片机为核心控制器，模拟真实共享单车的智能运营逻辑，打造了一套集硬件执行控制、双模无线通信、环境智能感知、数据持久存储、本地人机交互五大核心能力于一体的完整控制系统。项目完全贴合共享单车的实际使用场景，实现了从远程开锁、智能骑行、自动照明、数据统计到锁车断电、数据保存的全流程智能化控制，圆满完成了本次课设的设计要求。
二、核心功能模块介绍（分模块清晰讲解）
1. 车辆本体执行控制（基础核心功能）
这是系统最基础的硬件控制能力，模拟共享单车的机械与电气执行：
智能门锁控制：支持远程 / 本地自动开锁、关锁，实现车辆的启用与禁用；
骑行电机控制：开锁后可启动电机模拟骑行，锁车后自动断电关停；
提示蜂鸣器：开锁、锁车时发出不同提示音，反馈车辆状态；
所有执行机构均由单片机 GPIO 精准控制，响应迅速、逻辑稳定。
2. 双模无线通信（远程 + 本地，物联网核心）
为了兼顾远程云端控制和本地组网通信，我设计了WiFi+ZigBee 双模通信功能：
WiFi 通信（ESP8266 模块）：自动连接指定 WiFi，接入 TCP 服务器，接收服务器下发的开锁/锁车远程指令，同时向服务器上传车辆状态数据；
ZigBee 通信：支持本地无线组网，可响应本地终端的数据查询指令；
两种模式可通过按键一键切换，灵活适配不同使用场景。
3. 环境感知与智能照明（智能化亮点）
系统搭载光照传感器，实现自动化智能照明，完全模拟真实共享单车的夜间照明功能：
自动模式：实时采集环境光照强度，光线不足（天黑 / 阴天）或固定夜间时段，自动开启车灯；光线充足时自动关闭；
手动模式：支持用户本地按键手动开关车灯，两种模式自由切换；
还可通过按键调节光照阈值，适配不同环境需求。
4. 骑行数据统计与掉电存储（实用功能）
系统具备完善的数据统计和持久化能力，解决数据丢失问题：
里程统计：实时统计单次骑行里程和总骑行里程；
掉电不丢失：所有关键数据（总里程、历史记录等）写入单片机内部 FLASH，即使断电重启，数据也能自动恢复；
同时可采集环境相关数据，完成多维度数据记录。
5. 本地人机交互（可视化 + 便捷操作）
为了方便查看和本地控制，我设计了LCD 显示 + 物理按键的交互方案：
LCD 实时显示：屏幕上清晰展示当前时间、光照强度、车灯模式、骑行里程、通信模式、车辆开关状态等所有核心信息，一目了然；
按键本地控制：无需远程指令，通过四个按键即可实现：电机启停、车灯模式切换、通信模式切换、光照阈值调节，操作简单便捷。
6. 自动化指令解析
系统可自动解析远程 / 本地指令，无需人工干预：收到启动车辆指令自动开锁，收到停止车辆指令自动锁车、断电、存数据，全流程自动化运行。
三、系统整体工作流程
系统上电后，自动完成所有硬件初始化、WiFi 联网、历史数据读取；
等待远程服务器指令 或 本地按键操作；
收到开锁指令→自动开锁、提示音、进入骑行待命状态；
骑行过程中：自动统计里程、智能控制车灯、实时显示状态；
收到锁车指令→自动锁车、电机关停、数据存入 FLASH、恢复待机状态。
